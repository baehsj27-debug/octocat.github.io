# 배형서 | 보건의료행정학과 포트폴리오 (`github.io`)

보건의료행정학과 학생 **배형서**의 원페이지 포트폴리오 웹사이트입니다.

## 구성 파일
- `index.html`: 자기소개, 전공 핵심 역량, 프로젝트 및 영상 갤러리, 수정 기록 및 프롬프트 아카이브, 연락처(`010-8243-6848`)
- `과제.mp4`: 공중보건 감염예방 캠페인 영상
- `202611091402 (1).mp4`: 보건의료행정학과 전공 및 진로 소개 영상
- `.nojekyll`: GitHub Pages 정적 파일 호스팅 설정

## GitHub Pages 배포 방법
1. GitHub에 `본인아이디.github.io` (또는 원하는 저장소명)로 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `과제.mp4`, `202611091402 (1).mp4`, `.nojekyll` 파일을 저장소 최상단(루트)에 업로드합니다.
3. 저장소의 **Settings > Pages**에서 Branch를 `main`(또는 `master`), 폴더를 `/ (root)`로 설정하고 저장합니다.
4. 잠시 후 `https://본인아이디.github.io/` (또는 `https://본인아이디.github.io/저장소명/`) 주소로 접속해 확인합니다.
